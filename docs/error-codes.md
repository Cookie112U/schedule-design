# Справочник кодов ошибок

Пользователю показывается короткое сообщение и код. Подробности сохраняются в скрытом диагностическом журнале браузера:

- `sessionStorage["nttek-schedule-diagnostics"]`
- посмотреть из DevTools можно через `window.ScheduleErrorCatalog.getDiagnostics()`
- очистить через `window.ScheduleErrorCatalog.clearDiagnostics()`

## Коды

| Код | Значение |
| --- | --- |
| `NTT-SCH-001` | Не удалось загрузить расписание группы или преподавателя |
| `NTT-NET-001` | Нет подключения к сервису расписания |
| `NTT-NET-002` | Данные расписания не удалось получить из-за сетевого ограничения |
| `NTT-API-429` | Слишком много запросов |
| `NTT-API-404` | Запрошенные данные не найдены |
| `NTT-API-403` | Доступ к данным ограничен |
| `NTT-API-500` | Сервер расписания временно недоступен |
| `NTT-CAT-001` | Не загружены списки групп и преподавателей |
| `NTT-CAT-002` | Частично не загружены дополнительные данные |
| `NTT-TIME-001` | Не удалось уточнить время занятий |
| `NTT-ROOM-001` | Не удалось загрузить занятость аудиторий |
| `NTT-FILE-001` | Файл расписания для выбранной даты не найден |
| `NTT-APP-001` | Неизвестная ошибка интерфейса |
